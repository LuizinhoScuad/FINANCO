# Aprendizado do Guardião

Registro das decisões do Luiz sobre cada recomendação do Guardião. É o que
impede que uma sugestão já recusada volte a ser proposta.

**Este arquivo é versionado.** Portanto: apenas o padrão aprendido, **nunca**
dado de colaborador, valor ou recibo (Art. 4 — LGPD).

## Como usar

O Guardião lê este arquivo **antes** de formular qualquer recomendação. Após a
decisão do Luiz sobre um balde, registrar aqui.

## Formato

```
### AAAA-MM-DD — título curto da recomendação
- **Balde:** FAZER AGORA | OBSERVAR | DESCARTAR
- **Decisão:** aceita | recusada | adiada
- **Motivo:** por que — esta linha é a que ensina
```
